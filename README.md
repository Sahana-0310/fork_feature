# Student Management App

A beginner-friendly sample project built with HTML, CSS and JavaScript.

## Features

- View a sample student list
- Add a student with a name and course
- Remove a student
- See the student count update automatically

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Add and remove students to test the app.

No installation or build tools are required.

## Files

- `index.html` — page structure
- `style.css` — page styling
- `script.js` — app functionality

## Note

This is a front-end demo. Student data is stored in memory and resets when the page is refreshed.
